# PetCare+ — Pet Care Web App

PetCare+ is a responsive pet-care web application prototype built with HTML, CSS, and JavaScript. It brings everyday pet-care tasks, service discovery, appointment booking, and pet health information into one friendly interface.

## Features

- Pet-care dashboard and daily task tracking
- Veterinary, grooming, walking, and nutrition services
- Interactive appointment booking form
- Pet profile and health reminder sections
- Responsive mobile-friendly layout
- Interactive navigation and booking confirmation

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash pet photography

## Project Structure

## Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` with the Live Server extension.
4. Explore the app in your browser.

## Limitations

This is a front-end prototype. Appointments are not sent to a real clinic, and the app does not currently use a backend or database.
